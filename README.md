# Sportoverzicht

Al je sportdata in één app: Apple Gezondheid (Conditie, stappen, slaap, gewicht, MyFitnessPal, Technogym…), Strava (rechtstreekse koppeling) en Hevy (CSV-export of API). Trainingen die in meerdere apps staan, worden maar één keer geteld. Alle gegevens blijven in je eigen browser.

Open de app: https://h7m4yygc2f-design.github.io/Sportoverzicht/
